# Sales Data Analysis Using Excel

## Project Overview

This project analyzes sales data using Microsoft Excel to understand sales performance across different product categories.

## Tools Used

* Microsoft Excel
* GitHub

## Project Objectives

* Analyze total sales by product category.
* Compare sales performance across categories.
* Calculate key sales metrics.
* Create charts to visualize sales data.
* Present findings in a clear and understandable format.

## Project Work

* Organized and analyzed sales data in Excel.
* Calculated total sales by category.
* Created a pie chart to show sales contribution.
* Created a bar chart to compare category sales.
* Saved dashboard screenshots for presentation.

## Dashboard Preview

The dashboard screenshots are available in this repository.

## Key Learnings

* Excel-based data analysis.
* Sales calculations and aggregation.
* Data visualization.
* Project organization using GitHub.

## Conclusion

This project demonstrates the use of Microsoft Excel to analyze sales data and communicate business information through charts and visualizations.
